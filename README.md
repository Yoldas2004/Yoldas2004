## 🚀 Featured Projects

**[E-SporShop](https://github.com/Yoldas2004/E-SporShop)**
A sports-themed e-commerce application built with Blazor Server and .NET.
Organized as a three-layer solution (Web / Business / Data) following the
Repository and Service patterns. Uses EF Core Code-First with MySQL running in Docker,
Dependency Injection for loose coupling, and User Secrets for secure configuration.

**[HastaneRandevuSistemi](https://github.com/Yoldas2004/HastaneRandevuSistemi)**
A hospital appointment system built with WPF and ADO.NET. Features separate
Admin / Doctor / Patient role panels, BCrypt password hashing, soft-delete logic,
and race-condition prevention through unique constraints.

**[LibraryAutomationSys](https://github.com/Yoldas2004/LibraryAutomationSys)**
A library automation project developed in C#.
